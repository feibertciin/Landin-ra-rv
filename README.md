## 📌 Descripción del Proyecto

Esta **Landing Page** ha sido concebida y desarrollada para mostrar el impacto y la convergencia de las tecnologías de **Computación Espacial**:
- **Realidad Virtual (VR)**
- **Realidad Aumentada (AR)**
- **Realidad Mixta (MR)**

El proyecto destaca su aplicación práctica en el perfil profesional de un **Ingeniero de Sistemas** y su incorporación pedagógica en el rol de **Docente Universitario** dentro de la **Corporación Universitaria Lasallista**.

---

## 🎯 Características Principales

1. **Estilo Minimalista y Elegante**:
   - Diseño limpio con tipografía moderna (`Inter`), sombras suaves y efectos de *Glassmorphism*.
   - Sin uso de emoticones/emojis (cumpliendo estándares profesionales), utilizando **exclusivamente íconos vectoriales SVG**.

2. **Soporte Nativo de Tema Claro (Light Mode) y Tema Oscuro (Dark Mode)**:
   - Alternancia fluida mediante un botón de alternancia en la barra de navegación.
   - Persistencia automática de la preferencia del usuario en `localStorage`.

3. **Identidad Institucional Lasallista**:
   - Paleta de colores ajustada a la imagen institucional de la Corporación Universitaria Lasallista:
     - **Azul Marino Lasallista**: `#002B49`
     - **Dorado Lasallista**: `#F5B800`
     - **Rojo Borgoña**: `#A6192E`
     - **Cian / Acento Tecnológico**: `#00B4D8`

4. **Doble Perspectiva Profesional**:
   - **Ingeniero de Sistemas**: Visualización 3D de arquitecturas de software, monitoreo de ciberseguridad inmersivo y prototipado de interfaces espaciales.
   - **Docente Unilasallista**: Laboratorios inmersivos libres de riesgo, abstracción interactiva de algoritmos complejos y metodologías activas de aprendizaje.

5. **Simulador e Interacción en Tiempo Real**:
   - Demostrador interactivo que permite alternar visualmente entre los modos VR, AR y MR para observar su comportamiento contextualmente.

6. **Imágenes Generadas por Inteligencia Artificial**:
   - Galería de activos visuales de alta calidad dedicados a la computación espacial y la educación en ingeniería.

## 🚀 Cómo Visualizar el Proyecto

No se requieren dependencias externas de Node.js o servidores complejos. Puedes abrir directamente el archivo `index.html` en cualquier navegador moderno:

### Opción 1: Apertura directa
1. Descarga o clona el repositorio.
2. Haz doble clic sobre `index.html`.

### Opción 2: Servidor local (VS Code / Python / Live Server)
Si utilizas **VS Code**:
- Haz clic derecho sobre `index.html` y selecciona **Open with Live Server**.

Si utilizas **Python** desde la terminal:
```bash
python -m http.server 8000
```
Y abre tu navegador en `http://localhost:8000`.

- **HTML5**: Maquetación semántica y accesible (SEO optimizado).
